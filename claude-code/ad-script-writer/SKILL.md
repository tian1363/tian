# 广告脚本写作

## 使用流程

### 1. 识别产品与知识库
当用户请求写作广告脚本时，首先识别关联的产品：
- 如果是鸣潮产品，引用 `references/鸣潮的产品知识库.md`
- 如果用户提供了其他产品知识库，按需加载

### 2. 获取输入素材
- **原脚本内容**：用户提供希望改写或参考的现有脚本
- **参考视频**：用户提供希望模仿或获取灵感的视频素材
- **产品知识库**：根据识别的产品加载对应的知识库文档

### 3. 创作脚本
基于以下素材进行创作：
- 产品基础属性（世界观、受众画像、品牌调性）
- 产品玩法特征（核心循环、独特卖点、角色/职能）
- 视觉与交互标签（高光时刻、标志性符号、UI/操作）
- 营销与福利库（新手福利、版本热点、用户证言）

### 4. 输出脚本结构
广告脚本应包含：
- **开头**：吸引注意力（0-5秒）
- **核心内容**：产品亮点展示（5-20秒）
- **高潮/行动号召**：引导下载/转化（最后5秒）

## 参考资料

- 鸣潮产品知识库：`references/鸣潮的产品知识库.md`

## 注意事项

- 确保脚本符合产品知识库中的品牌调性
- 突出产品独特卖点，避免同质化
- 结合版本热点进行创作
- 时长控制在15-60秒为宜
