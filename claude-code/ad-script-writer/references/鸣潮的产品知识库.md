产品特征库分为四个核心维度：基础属性、玩法特征、视觉与交互标签、营销与福利库。

## 1. 基础属性 (Basic Identity)

### 核心世界观
未来科幻与幻想融合的开放世界设定，包含灾变背景与多阵营势力冲突。  
美术风格为高精度二次元渲染，色彩饱和度高，角色与场景细节丰富。  
广告视频中进一步强调多人协作探索、阵营对抗氛围，以及副本挑战的紧张感。  
新增素材中出现阵营战场景、新地图环境与动态天气系统，强化了世界观的动态变化与持续更新感。  
跨服阵营战的引入让世界观具备跨服务器的社交与竞技延展性。  
最新视频中展示了新角色登场与高爆发技能释放，进一步丰富了世界观中的战斗层次。  
本次新增素材特别呈现天气变化对战局的实时影响，以及新角色在阵营战中快速清场并提供全队增益的场景。  
新增昼夜交替与环境互动机制（如：特定时间触发隐藏任务、环境元素可用于战斗策略），提升沉浸感与策略深度。  
新素材还展示了阵营战专属战术部署UI、天气预警与技能联动提示、昼夜交替触发特殊任务的动态演出，以及新角色在不同环境条件下的技能适应性表现，强化了战术多样性与视觉冲击力。  
天气变化与昼夜交替在同一战局中产生叠加效果，玩家需通过战术部署UI实时调整技能释放与站位；环境互动元素（如风向、光照变化）可触发额外增益或限制效果，增加战局变数与策略深度。  
极端天气（暴风雪、雷暴）与地形变化（地裂、洪水）叠加机制，形成不可预测的战局变数，玩家可利用环境触发连锁反应（如洪水冲击敌方阵地、地裂隔断敌军），增加生存挑战与策略创造性。  
沙尘暴与酸雨等环境危害可持续削弱玩家状态或限制移动；资源点会因环境变化而刷新位置，形成动态争夺战局。  
**新增发现**：极端天气类型扩展至黑雾与流星雨，特殊地形包括悬浮裂岛与雷暴峡谷，环境危害可造成视野遮蔽、范围性高伤害或地形崩塌，迫使玩家进行高频战术转场与资源争夺。

## 2. 玩法特征 (Mechanics & USP)

### 核心循环
探索开放世界 → 收集资源与任务 → 战斗挑战 → 角色养成与装备强化。  
多人副本挑战 → Boss战 → 奖励领取，强调协作技能链与战术配合。  
阵营对抗循环：阵营任务 → 战场交锋 → 积分排名 → 阵营奖励。  
跨服阵营战循环：跨服匹配 → 战场策略部署 → 实时天气影响战局 → 胜利奖励。  
新角色循环：解锁 → 技能升级 → 在副本与阵营战中发挥高爆发输出。  
天气变化触发特殊战术技能链，以及新角色快速清场并提供全队增益的玩法。  
昼夜交替循环：特定时间段触发隐藏任务 → 环境元素互动 → 战斗策略调整。  
阵营战专属战术部署UI与天气预警提示，玩家可根据环境变化调整技能释放与战术布局。  
天气与昼夜交替同时影响战局时，核心循环增加“环境监控 → 战术调整 → 技能联动 → 队伍增益”的即时应对环节。  
极端天气与地形变化叠加时，核心循环增加“环境监测 → 连锁反应触发 → 战局反制 → 队伍协作”的高压策略环节。  
沙尘暴与酸雨等持续性环境危害引入“状态维护 → 资源争夺 → 环境适应 → 战术转场”的生存博弈循环。  
**新增发现**：黑雾与流星雨引入“视野管理 → 高危区域规避 → 资源抢夺 → 地形利用”的高风险循环；悬浮裂岛与雷暴峡谷增加“空中机动 → 地形触发事件 → 战术高地争夺”的立体战斗循环。

- 阵营战中可触发大规模技能链与战略部署，强调团队战术
- 跨服阵营战与动态天气系统，增加战术多变性与竞技公平性
- 新角色高爆发技能与团队增益效果，提升战斗效率与策略多样性
- 天气变化与技能释放的联动机制，增加战局策略深度
- 昼夜交替与环境互动机制，增加探索乐趣与战术多样性

- 双环境变量叠加的战局应对机制，强调多变量策略与团队协作。  
- 极端天气+地形变化叠加机制，允许玩家利用环境触发连锁反应。  
- 环境危害与资源争夺结合的玩法，形成差异化的生存+竞技混合体验。  
**新增发现**：黑雾与流星雨等高危环境与悬浮裂岛、雷暴峡谷等立体地形结合，形成独特的空地一体化战术体验。
